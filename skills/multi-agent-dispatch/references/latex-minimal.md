# LaTeX 最小改动

只在任务涉及 LaTeX 论文、报告或模板时读取。遵守用户指定的目录、权限、目标版本及验收条件。

1. 先读取任务涉及的 `.tex`、类文件和已有构建方式，确认目标片段、相关输入、宏包、交叉引用以及本次允许修改的文件。将必要范围和不可变项写入交接。
2. 优先局部编辑，保留文档结构、原有排版和格式、宏与环境、`\label` / `\ref` / `\cite` 标识、公式及其数学语义。只有任务明确要求时才改变它们。避免无关重排或批量格式化。
3. 在授权范围内使用项目现有引擎与构建命令编译，按实际需要运行参考文献和多轮编译。检查退出码、日志中的错误、未定义引用与新增警告，并核对受影响页面、公式和引用。
4. 报告修改文件、构建命令与退出码、检查结果和剩余警告。构建依赖缺失或未获准编译时如实标注，不能以文本检查声称编译通过。已知编译失败按原执行归属与剩余预算修订。
