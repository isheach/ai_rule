# 科研与量化任务的可复现性

只在涉及实验、研究、数据或量化策略时读取。遵守已有项目授权、隐私约束、研究协议与用户验收标准。

1. 明确研究问题、数据来源与版本、样本范围、单位、时区、训练/验证/测试及回测窗口、拆分与基线。记录可用的数据快照、代码修订、依赖/运行环境版本、参数和随机种子。未知项标为未知，不虚构。
2. 在设计及复核中检查时间顺序、数据可得时点、预处理和特征拟合的边界，防止未来信息、跨窗口或训练/测试泄漏。涉及交易策略时记录适用的交易成本、滑点、执行与复权等假设，避免把回测表现当成未来保证。
3. 在获准范围内按项目既有命令复现或检验，保留运行命令、退出码、输入版本、输出位置与指标，比较基线并报告窗口和参数差异。不能运行或数据不可用时区分已有结果与未验证结论。
4. 交接只传完成任务所需的可共享事实、合同和证据。敏感数据、凭据与私有日志留在原机器。结果应让后续接手者可以定位版本和运行条件，同时保留限制、失败及未完成检查。
